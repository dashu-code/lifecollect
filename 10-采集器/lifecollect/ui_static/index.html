    导入材料

    把真实材料放进档案。导入之后会自动标注、建索引、重写清单—— 不需要再去命令行跑任何东西。

    1
    这些材料是什么
    来源影响标注方式，也影响它们被当成什么级别的证据。
    2
    选择文件或文件夹
    支持 CSV、TXT、JSON、JSONL、HTML、MD。也可以直接选一个文件夹， 里面的语音、图片、视频会被登记。
    或者直接粘贴路径
    3
    哪个名字是你
    不填也没关系，但所有消息的方向会标成"未知"。 "不知道是谁"和"知道是对方"是两回事——猜错会让下游 把别人的话当成档案主人的。
    选完文件后，这里会列出出现过的名字，点一下就能标记为你。
    高级：来源可信级别
    级别 2（默认）：手机端整体备份 / 直接导出。 如果能直接读取数据库（级别 1），时间精度和语音都会更好。
    '
    AI 协助起草 可选 · 会联网 · 默认关闭
    先说清楚这件事

    这个功能会联网。档案的其他所有功能都在本机完成， 只有这里例外。启用后，你输入的「主题」和「依据」会发送给你配置的 AI 服务商（DeepSeek / OpenAI 等）。档案里的记录、授权内容、 密钥，一律不会上传。

    AI 写的东西不是本人写的。它只能用来整理 外部公开材料（比如查一段公开报道、整理某个事件的公开信息）。 不要用它回忆你的私人经历——它会编，而且编得像真的。 所有草稿必须你逐句核对后才能保存，保存后会标记为「AI 协助起草」。

    A
    配置服务商
    API Key 加密后存在本地档案里，不会发给任何第三方。
    B
    让它起草
    主题写清楚你要整理什么。依据里只放你确认过的事实，它会严格按依据写， 没有依据的地方会标注「不确定」。
    D
    批量整理已有材料
    让它读你已经导入的记录，归纳成时间线、人物、主题， 并列出矛盾和信息缺口。每条结论后面会标出处记录 ID—— 你可以逐条核对。它只做归纳，不产生新事实。
    先算一下
    核对摘要 每条都要能追到出处记录
    C
    逐句核对，改完才能保存
    下面是草稿，可以直接编辑。删掉任何你不确认的内容。 保存后它会以「AI 协助起草」的身份进档案——这个标记会一直跟着它， 不会混进"你写的东西"里。

    检索

    中文按字符级索引，单字、双字、跨词边界都能查。短语匹配要求连续，宁可漏不可错。

    呈现

    这些文件是给人看的，不需要任何工具就能打开。其中《待处理问题》主动列出这份档案的毛病。

    授权

    任何使用本档案的人必须先读这里。未填写的项一律按禁止处理。 改完点保存，人类可读的授权声明会同步重写。

    逐项授权 —
    签署
    身后指令 你去世后，谁有权决定这份档案怎么用
    密钥托管方式（只读） 
    
        
    
      
    
    
    

    
    
    
      
    
        
    加密
    
        
    说明文件和授权目录永远明文——否则没人知道这是什么、谁能用。其余内容锁起来。

    加锁
